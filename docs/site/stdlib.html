Standard Library Reference

The Fin standard library lives in lib/std/ and ships beside the finc compiler. All modules declare their members under namespace std and are imported using from <module>::std. Fin treats memory models as modular libraries rather than compiler burdens, providing zero-overhead, deterministic systems facilities.

stdio

stdio::std Core & I/O

Terminal I/O, formatted output, the Printable interface contract, in-memory Stream byte buffers, and static File operations. printf is ambient and available without imports via #[global].

Note: printf is declared ambiently in stdio with #[global]. Any file can call printf without an import statement.
Import Statement 
import { print, println, eprint, eprintln, Printable, Stream, IStream, File, IOResult, IOError } from stdio::std;

API Interface & Signatures

Signature Type Description
printf(fmt: string, ...) <noret> Global Function Ambient C-style variadic formatted print to stdout.
print<X: Printable>(item: X) <noret> Generic Function Outputs item to stdout using format_str().
println<X: Printable>(item: X) <noret> Generic Function Outputs item to stdout followed by a newline.
eprint(msg: string) <noret> Function Writes raw string to standard error (stderr).
eprintln(msg: string) <noret> Function Writes string to standard error followed by a newline.
struct Stream : <IStream> Struct In-memory byte stream over [char] buffer. Methods: seek, tell, remaining, rewind, read, read_all, write, capacity, expand.
struct File Struct Static filesystem methods: exists(path) <bool>, size(path) <long>, read_all(path) <string>, write_text(path, text) <bool>, append_text(path, text) <bool>, remove(path) <bool>.
enum IOResult<T> Enum Result enum for I/O operations: Ok(T) or Err(IOError).
enum IOError Enum I/O failure modes: NotFound, PermissionDenied, AlreadyExists, InvalidInput, UnexpectedEof.
interface Printable Interface pub fun format_str(self: &Self) <string>;
Memory & Safety Semantics: Stream buffers are caller-allocated. File::read_all produces a heap-allocated string that the caller owns. File methods open and close file descriptors deterministically.

Usage Example

stdio_example.fin 
@define printf(fmt: string, ...) <noret>;
import { print, println, Printable } from stdio::std;

struct Metric : <Printable> {
    label <string>,
    value <int>,

    pub fun format_str(self: &Self) <string> {
        return self.label;
    }
}

fun main() <noret> {
    let m <Metric> = Metric { label: "cpu_temperature_celsius", value: 45 };
    println::<Metric>(m);

    printf("Metric value: %d\n", m.value);
}

fs

fs::std Core & I/O

Direct filesystem interaction: checking file existence, querying file sizes, reading entire files into memory strings, writing, appending, and removing files.

Note: Reaches standard C runtime file I/O primitives (fopen, fclose, fseek, ftell, fread, fwrite, remove).
Import Statement 
import { file_exists, remove_file, file_size, read_to_string, write_string, append_string, free_file_content } from fs::std;

API Interface & Signatures

Signature Type Description
file_exists(path: string) <bool> Function Checks if a file exists and can be opened for reading.
remove_file(path: string) <bool> Function Deletes the file at path. Returns true on success, false on failure.
file_size(path: string) <long> Function Returns the size of the file in bytes, or -1 if the file cannot be accessed.
read_to_string(path: string) <string?> Function Reads entire file into a newly allocated string. Returns null if read fails.
write_string(path: string, content: string) <bool> Function Overwrites the file at path with content. Returns true on success.
append_string(path: string, content: string) <bool> Function Appends content to the end of the file at path. Returns true on success.
free_file_content(s?: string) <noret> Function Frees the heap buffer returned by read_to_string.
Memory & Safety Semantics: Strings returned by read_to_string are heap-allocated via calloc. The caller owns the string and must release it with free_file_content(s).

Usage Example

fs_example.fin 
@define printf(fmt: string, ...) <noret>;
import { file_exists, write_string, read_to_string, free_file_content, remove_file } from fs::std;

fun main() <noret> {
    let path <string> = "/tmp/fin_app.conf";
    let written <bool> = write_string(path, "debug=true\nworkers=4\n");
    blame written, "Failed to write configuration";

    blame file_exists(path);

    let content? <string> = read_to_string(path);
    if (content != null) {
        printf("Config loaded:\n%s", content?);
        free_file_content(content);
    }

    remove_file(path);
}

path

path::std Core & I/O

Filesystem path manipulation: safe segment joining, basename and dirname extraction, extension checking, and absolute vs relative path inspection.

Note: Path operations handle slashes cleanly without producing duplicate slashes.
Import Statement

API Interface & Signatures

Signature Type Description
is_absolute(path: string) <bool> Function Returns true if path starts with root slash /.
is_relative(path: string) <bool> Function Returns true if path does not start with root slash.
join(p1: string, p2: string) <string> Function Joins two paths with / separator. Returns p2 if p2 is absolute.
basename(path: string) <string> Function Extracts the final filename component after the last /.
dirname(path: string) <string> Function Extracts the directory prefix preceding the last /.
extname(path: string) <string> Function Extracts file extension including leading dot (e.g. ".fin").
free_path(s: string) <noret> Function Frees a heap-allocated path string returned by join, basename, dirname, or extname.
Memory & Safety Semantics: Strings produced by join, basename, dirname, and extname are heap-allocated. Caller owns the buffer and frees it via free_path(s).

Usage Example

path_example.fin 
@define printf(fmt: string, ...) <noret>;
import { is_absolute, join, basename, dirname, extname, free_path } from path::std;

fun main() <noret> {
    let full <string> = "/home/user/src/main.fin";
    blame is_absolute(full);

    let base <string> = basename(full);
    let dir <string> = dirname(full);
    let ext <string> = extname(full);

    blame ext == ".fin";
    printf("Dir: %s, File: %s, Ext: %s\n", dir, base, ext);

    let next <string> = join(dir, "build.sh");
    printf("Next target: %s\n", next);

    free_path(base);
    free_path(dir);
    free_path(ext);
    free_path(next);
}

collection

collection::std Collections

The primary growable dynamic array Collection<T>. Backed by [T] with geometric buffer doubling, capacity reservations, and strict runtime bounds checking via blame.

Note: Collection wraps a [T] heap array. Growth allocates a fresh buffer and copies elements.
Import Statement 
import { Collection } from collection::std;

API Interface & Signatures

Signature Type Description
push(val: T) <noret> Method Appends element to end of collection, doubling buffer capacity when full.
pop_last() <T> Method Removes and returns the final element. Blames if empty.
get(index: int) <T> Method Returns element at index. Blames if out of bounds.
set(index: int, val: T) <noret> Method Assigns element at index. Blames if out of bounds.
len() <int> Method Returns active element count.
capacity() <int> Method Returns current extent of allocated [T] buffer.
is_empty() <bool> Method Returns true if len() == 0.
clear() <noret> Method Resets count to 0 without releasing buffer.
first() <T> Method Returns element at index 0. Blames if empty.
last() <T> Method Returns element at index len() - 1. Blames if empty.
contains(val: T) <bool> Method Performs linear search for val, returning true if found.
index_of(val: T) <int> Method Returns 0-based index of first matching element, or -1.
insert(index: int, val: T) <noret> Method Inserts element at index, shifting remaining elements right.
remove(index: int) <T> Method Removes element at index, shifting remaining elements left and returning item.
reverse() <noret> Method Reverses elements in-place.
extend(other: &Self) <noret> Method Appends all elements from another Collection.
reserve(additional: int) <noret> Method Pre-allocates capacity to avoid intermediate reallocations.
Memory & Safety Semantics: Collection manages its own internal [T] heap buffer. Elements are stored contiguously in memory.

Usage Example

collection_example.fin 
@define printf(fmt: string, ...) <noret>;
import { Collection } from collection::std;

fun main() <noret> {
    let numbers <Collection<int>> = Collection<int>{};
    numbers.push(10);
    numbers.push(20);
    numbers.push(30);

    blame numbers.len() == 3;
    blame numbers.get(0) == 10;
    blame numbers.get(2) == 30;

    let popped <int> = numbers.pop_last();
    blame popped == 30;
    blame numbers.len() == 2;

    printf("Numbers in list: %d, first: %d, last: %d\n", numbers.len(), numbers.first(), numbers.last());
}

hashmap

hashmap::std Collections

Associative key-value map HashMap<K, V> using open addressing with linear probing and a 0.75 load factor threshold for automatic rehashing.

Note: Stores keys, values, hash codes, and bucket states in contiguous internal vectors.
Import Statement 
import { HashMap } from hashmap::std;

API Interface & Signatures

Signature Type Description
put(key: K, value: V) <noret> Method Inserts or updates key-value pair. Triggers rehash if load factor > 0.75.
get(key: K) <V> Method Retrieves value associated with key. Blames if key is absent.
remove(key: K) <bool> Method Removes key and value from table. Returns true if key was present.
contains_key(key: K) <bool> Method Returns true if key exists in hash table.
size() <int> Method Returns number of active key-value entries.
is_empty() <bool> Method Returns true if size() == 0.
clear() <noret> Method Clears all entries and resets table to initial state.
Memory & Safety Semantics: HashMap owns its internal allocation buffers. Keys and values are copied into table entries.

Usage Example

hashmap_example.fin 
@define printf(fmt: string, ...) <noret>;
import { HashMap } from hashmap::std;

fun main() <noret> {
    let scores <HashMap<string, int>> = HashMap<string, int>{};
    scores.put("Alice", 95);
    scores.put("Bob", 88);
    scores.put("Charlie", 92);

    blame scores.size() == 3;
    blame scores.contains_key("Alice");
    blame scores.get("Charlie") == 92;

    scores.remove("Bob");
    blame !scores.contains_key("Bob");
    blame scores.size() == 2;

    printf("Active players: %d, Alice score: %d\n", scores.size(), scores.get("Alice"));
}

operators

operators::std Types & Semantics

Interfaces for user-defined operator overloading on structs: arithmetic, comparison, and index assignment.

Note: Struct conformance enables syntactic operator sugar with direct method dispatch.
Import Statement 
import { IndexAssign, Add, Sub, Mul, Div, Equals } from operators::std;

API Interface & Signatures

Signature Type Description
interface IndexAssign<T> Interface Enables arr[i] = val: pub operator []=(index: int, val: T) <noret>;
interface Add<T> Interface Enables a + b: pub operator +(other: T) <T>;
interface Sub<T> Interface Enables a - b: pub operator -(other: T) <T>;
interface Mul<T> Interface Enables a * b: pub operator *(other: T) <T>;
interface Div<T> Interface Enables a / b: pub operator /(other: T) <T>;
interface Equals<T> Interface Enables a == b: pub operator ==(other: T) <bool>;
Memory & Safety Semantics: Operators are lowered to direct method calls with zero allocation overhead.

Usage Example

operators_example.fin 
@define printf(fmt: string, ...) <noret>;
import { Add } from operators::std;

struct Vector2D : <Add<Vector2D>> {
    x <int>,
    y <int>,

    pub operator +(other: Vector2D) <Vector2D> {
        return Vector2D { x: self.x + other.x, y: self.y + other.y };
    }
}

fun main() <noret> {
    let a <Vector2D> = Vector2D { x: 10, y: 20 };
    let b <Vector2D> = Vector2D { x: 5, y: 15 };
    let c <Vector2D> = a + b;

    blame c.x == 15 && c.y == 35;
    printf("Vector sum: (%d, %d)\n", c.x, c.y);
}

memory

memory (Core & Custom) Memory & Pointers

Explicit memory allocation mechanisms: native heap dynamic arrays new [T, n]{}, delete arr;, and user-defined arena allocators for high-throughput batch lifetimes.

Note: Fin has no background garbage collector. Memory is explicitly managed via arrays or custom allocators.
Import Statement 
// Memory is an explicit library, not a rigid compiler burden\n// Core allocation: new [T, n]{} and delete arr;

API Interface & Signatures

Signature Type Description
new [T, n]{} Syntax Operator Allocates heap dynamic array of type T and length n, zero-initializing elements. Produces [T].
delete arr; Syntax Statement Frees the heap element buffer associated with dynamic array [T].
new T; Syntax Operator Allocates single instance of type T on heap, returning raw pointer *T.
delete ptr; Syntax Statement Frees single heap pointer *T.
struct Arena Pattern Linear bump allocator pattern: arena.alloc(bytes), arena.reset(), arena.destroy().
Memory & Safety Semantics: Explicit manual memory semantics. Every heap allocation must be paired with delete by its owner.

Usage Example

memory_example.fin 
@define printf(fmt: string, ...) <noret>;

fun main() <noret> {
    let size <int> = 16;
    let buffer <[int]> = new [int, size]{};

    for (let i <int> = 0; i < buffer.length; i++) {
        buffer[i] = i * i;
    }

    blame buffer.length == 16;
    blame buffer[4] == 16;

    printf("Allocated %d items, element 4 = %d\n", buffer.length, buffer[4]);

    delete buffer;  // Explicit deallocation
}

stdptr

stdptr::std Memory & Pointers

Smart pointer rptr<T> providing sound reference-counted memory sharing with explicit retain/release lifecycle tracking.

Note: Tracks shared reference count to prevent use-after-free and double-free defects.
Import Statement 
import { rptr, OwnershipError } from stdptr::std;

API Interface & Signatures

Signature Type Description
struct rptr<T> Struct Reference-counted pointer wrapping ptr <&T> and ref_count <int>. Methods: retain(), release(), get() <&T>, count() <int>.
enum OwnershipError Enum Ownership defect classification: DoubleFree, DanglingPointer, LeakDetected.
Memory & Safety Semantics: rptr tracks shared references. When the reference count reaches 0, the resource is released.

Usage Example

stdptr_example.fin 
@define printf(fmt: string, ...) <noret>;
import { rptr } from stdptr::std;

struct BufferHandle {
    fd <int>,
    capacity <int>
}

fun main() <noret> {
    let handle <BufferHandle> = BufferHandle { fd: 3, capacity: 4096 };
    let smart <rptr<BufferHandle>> = rptr<BufferHandle> { ptr: &handle, ref_count: 1 };

    smart.retain();
    blame smart.count() == 2;

    smart.release();
    blame smart.count() == 1;

    printf("Handle fd: %d, capacity: %d, active refs: %d\n", smart.get().fd, smart.get().capacity, smart.count());
}
