Standard Library Reference

The Fin standard library lives in lib/std/ and ships beside the finc compiler. All modules declare their members under namespace std and are imported using from <module>::std.

stdio

stdio::std Core & I/O

Terminal I/O, formatted output, the Printable interface contract, in-memory Stream byte buffers, and static File operations. printf is ambient and available without imports via #[global].

Note: printf is declared ambiently in stdio with #[global]. Any file can call printf without an import statement.
Import Statement 
import { print, println, eprint, eprintln, Printable, Stream, IStream, File, IOResult, IOError } from stdio::std;

API Interface & Signatures

Signature Type Description
printf(fmt: string, ...) <noret> Global Function Ambient C-style variadic formatted print to stdout.
print<X: Printable>(item: X) <noret> Generic Function Outputs item to stdout using format_str().
println<X: Printable>(item: X) <noret> Generic Function Outputs item to stdout followed by a newline.
eprint(msg: string) <noret> Function Writes raw string to standard error (stderr).
eprintln(msg: string) <noret> Function Writes string to standard error followed by a newline.
struct Stream : <IStream> Struct In-memory byte stream over [char] buffer. Methods: seek, tell, remaining, rewind, read, read_all, write, capacity, expand.
struct File Struct Static filesystem methods: exists(path) <bool>, size(path) <long>, read_all(path) <string>, write_text(path, text) <bool>, append_text(path, text) <bool>, remove(path) <bool>.
enum IOResult<T> Enum Result enum for I/O operations: Ok(T) or Err(IOError).
enum IOError Enum I/O failure modes: NotFound, PermissionDenied, AlreadyExists, InvalidInput, UnexpectedEof.
interface Printable Interface pub fun format_str(self: &Self) <string>;
Memory & Safety Semantics: Stream buffers are caller-allocated. File::read_all produces a heap-allocated string that the caller owns. File methods open and close file descriptors deterministically.

Usage Example

stdio_example.fin 
@define printf(fmt: string, ...) <noret>;
import { print, println, Printable } from stdio::std;

struct Metric : <Printable> {
    label <string>,
    value <int>,

    pub fun format_str(self: &Self) <string> {
        return self.label;
    }
}

fun main() <noret> {
    let m <Metric> = Metric { label: "cpu_temperature_celsius", value: 45 };
    println::<Metric>(m);

    printf("Metric value: %d\n", m.value);
}

fs

fs::std Core & I/O

Direct filesystem interaction: file existence, sizes, whole-file reads, writes and appends, copies, directory creation and walks, and mkdtemp scratch dirs.

Note: Reaches standard C runtime file I/O and directory primitives (fopen, fclose, fseek, ftell, fread, fwrite, fputs, remove, mkdir, rmdir, rename, opendir, readdir, closedir, rewinddir, memcpy, mkdtemp). walk_dir copies each dirent through memcpy and reads the name at the Linux x86-64 glibc offsets (name at byte 19, d_reclen at 16..17) -- the library has no pointer arithmetic.
Import Statement 
import { file_exists, remove_file, file_size, read_to_string, write_string, append_string, free_file_content, copy_file, create_dir, remove_dir, rename_path, is_dir, is_file, mk_tmp_dir, mkdir_p, walk_dir } from fs::std;

API Interface & Signatures

Signature Type Description
file_exists(path: string) <bool> Function Checks if a file exists and can be opened for reading.
remove_file(path: string) <bool> Function Deletes the file at path. Returns true on success, false on failure.
file_size(path: string) <long> Function Returns the size of the file in bytes, or -1 if the file cannot be accessed.
read_to_string(path: string) <string?> Function Reads entire file into a newly allocated string. Returns null if read fails.
write_string(path: string, content: string) <bool> Function Overwrites the file at path with content. Returns true on success.
append_string(path: string, content: string) <bool> Function Appends content to the end of the file at path. Returns true on success.
free_file_content(s?: string) <noret> Function Frees the heap buffer returned by read_to_string.
copy_file(src: string, dst: string) <bool> Function Copies a whole file byte for byte. A missing source reads null and answers false.
create_dir(path: string) <bool> Function Makes one directory (mode 0755). True on success.
remove_dir(path: string) <bool> Function Removes one empty directory (rmdir). True on success.
rename_path(old_path: string, new_path: string) <bool> Function Moves or renames a file. True on success.
is_dir(path: string) <bool> Function True when opendir opens the path as a directory.
is_file(path: string) <bool> Function True when the path opens for reading and is not a directory.
mk_tmp_dir(prefix: string) <string?> Function A fresh uniquely-named directory under /tmp: prefix plus the six characters mkdtemp overwrites. The name is fresh memory; release with free_str.
mkdir_p(path: string) <bool> Function mkdir -p: every missing directory on the way to path. Prefixes that already exist are not failures.
walk_dir(path: string) <[string]> Function The entries of one directory with the dots left out, in readdir's order. delete the array and free_str each entry.
Memory & Safety Semantics: Strings returned by read_to_string are heap-allocated via calloc. The caller owns the string and must release it with free_file_content(s). Paths from concat, mk_tmp_dir's name, and each walk_dir entry are also caller-owned: free_str each and delete the walk_dir array. A missing file is routine, never a fault: read_to_string answers null, file_size answers -1, walk_dir answers an empty array.

Usage Example

fs_example.fin 
@define printf(fmt: string, ...) <noret>;
import { file_exists, write_string, read_to_string, free_file_content, remove_file } from fs::std;

fun main() <noret> {
    let path <string> = "/tmp/fin_app.conf";
    let written <bool> = write_string(path, "debug=true\nworkers=4\n");
    blame written, "Failed to write configuration";

    blame file_exists(path);

    let content? <string> = read_to_string(path);
    if (content != null) {
        printf("Config loaded:\n%s", content?);
        free_file_content(content);
    }

    remove_file(path);
}

path

path::std Core & I/O

Filesystem path manipulation: safe segment joining, basename and dirname extraction, extension checking, and absolute vs relative path inspection.

Note: Path operations handle slashes cleanly without producing duplicate slashes.
Import Statement 
import { is_absolute, is_relative, join, basename, dirname, extname, free_path } from path::std;

API Interface & Signatures

Signature Type Description
is_absolute(path: string) <bool> Function Returns true if path starts with root slash /.
is_relative(path: string) <bool> Function Returns true if path does not start with root slash.
join(p1: string, p2: string) <string> Function Joins two paths with / separator. Returns p2 if p2 is absolute.
basename(path: string) <string> Function Extracts the final filename component after the last /.
dirname(path: string) <string> Function Extracts the directory prefix preceding the last /.
extname(path: string) <string> Function Extracts file extension including leading dot (e.g. ".fin").
free_path(s: string) <noret> Function Frees a heap-allocated path string returned by join, basename, dirname, or extname.
Memory & Safety Semantics: Strings produced by join, basename, dirname, and extname are heap-allocated. Caller owns the buffer and frees it via free_path(s).

Usage Example

path_example.fin 
@define printf(fmt: string, ...) <noret>;
import { is_absolute, join, basename, dirname, extname, free_path } from path::std;

fun main() <noret> {
    let full <string> = "/home/user/src/main.fin";
    blame is_absolute(full);

    let base <string> = basename(full);
    let dir <string> = dirname(full);
    let ext <string> = extname(full);

    blame ext == ".fin";
    printf("Dir: %s, File: %s, Ext: %s\n", dir, base, ext);

    let next <string> = join(dir, "build.sh");
    printf("Next target: %s\n", next);

    free_path(base);
    free_path(dir);
    free_path(ext);
    free_path(next);
}

collection

collection::std Collections

The primary growable dynamic array Collection<T>. Backed by [T] with geometric buffer doubling, capacity reservations, and strict runtime bounds checking via blame.

Note: Collection wraps a [T] heap array. Growth allocates a fresh buffer and copies elements.
Import Statement 
import { Collection } from collection::std;

API Interface & Signatures

Signature Type Description
push(val: T) <noret> Method Appends element to end of collection, doubling buffer capacity when full.
pop_last() <T> Method Removes and returns the final element. Blames if empty.
get(index: int) <T> Method Returns element at index. Blames if out of bounds.
set(index: int, val: T) <noret> Method Assigns element at index. Blames if out of bounds.
len() <int> Method Returns active element count.
capacity() <int> Method Returns current extent of allocated [T] buffer.
is_empty() <bool> Method Returns true if len() == 0.
clear() <noret> Method Resets count to 0 without releasing buffer.
first() <T> Method Returns element at index 0. Blames if empty.
last() <T> Method Returns element at index len() - 1. Blames if empty.
contains(val: T) <bool> Method Performs linear search for val, returning true if found.
index_of(val: T) <int> Method Returns 0-based index of first matching element, or -1.
insert(index: int, val: T) <noret> Method Inserts element at index, shifting remaining elements right.
remove(index: int) <T> Method Removes element at index, shifting remaining elements left and returning item.
reverse() <noret> Method Reverses elements in-place.
extend(other: &Self) <noret> Method Appends all elements from another Collection.
reserve(additional: int) <noret> Method Pre-allocates capacity to avoid intermediate reallocations.
Memory & Safety Semantics: Collection manages its own internal [T] heap buffer. Elements are stored contiguously in memory.

Usage Example

collection_example.fin 
@define printf(fmt: string, ...) <noret>;
import { Collection } from collection::std;

fun main() <noret> {
    let numbers <Collection<int>> = Collection<int>{};
    numbers.push(10);
    numbers.push(20);
    numbers.push(30);

    blame numbers.len() == 3;
    blame numbers.get(0) == 10;
    blame numbers.get(2) == 30;

    let popped <int> = numbers.pop_last();
    blame popped == 30;
    blame numbers.len() == 2;

    printf("Numbers in list: %d, first: %d, last: %d\n", numbers.len(), numbers.first(), numbers.last());
}

hashmap

hashmap::std Collections

Associative key-value map HashMap<K, V> using open addressing with linear probing and a 0.75 load factor threshold for automatic rehashing.

Note: Stores keys, values, hash codes, and bucket states in contiguous internal vectors.
Import Statement 
import { HashMap } from hashmap::std;

API Interface & Signatures

Signature Type Description
put(key: K, value: V) <noret> Method Inserts or updates key-value pair. Triggers rehash if load factor > 0.75.
get(key: K) <V> Method Retrieves value associated with key. Blames if key is absent.
remove(key: K) <bool> Method Removes key and value from table. Returns true if key was present.
contains_key(key: K) <bool> Method Returns true if key exists in hash table.
size() <int> Method Returns number of active key-value entries.
is_empty() <bool> Method Returns true if size() == 0.
clear() <noret> Method Clears all entries and resets table to initial state.
Memory & Safety Semantics: HashMap owns its internal allocation buffers. Keys and values are copied into table entries.

Usage Example

hashmap_example.fin 
@define printf(fmt: string, ...) <noret>;
import { HashMap } from hashmap::std;

fun main() <noret> {
    let scores <HashMap<string, int>> = HashMap<string, int>{};
    scores.put("Alice", 95);
    scores.put("Bob", 88);
    scores.put("Charlie", 92);

    blame scores.size() == 3;
    blame scores.contains_key("Alice");
    blame scores.get("Charlie") == 92;

    scores.remove("Bob");
    blame !scores.contains_key("Bob");
    blame scores.size() == 2;

    printf("Active players: %d, Alice score: %d\n", scores.size(), scores.get("Alice"));
}

btreemap

btreemap::std Collections

The ordered map BTreeMap<K, V>: two parallel arrays kept sorted under the caller's comparator. Index order is sorted order, in every compiler at every opt level -- the determinism contract codegen iteration needs.

Note: Key ordering is the caller's `less <fn(K, K) -> bool>` comparator (a function field, not a bound -- the reasoning HashMap's header records); "equal" is the two-sided idiom `!f(a, b) && !f(b, a)`. This is spine search, not a balanced tree: insert is O(n) and the module says so honestly. Ownership: the map stores the key/value words as they arrived; free_btree_map frees the arrays, never the stored words. Spell the instantiation on the receiver (`<BTreeMap<string, int>>`), an `<auto>` receiver is refused by the stage checkers.
Import Statement 
import { BTreeMap } from btreemap::std;

API Interface & Signatures

Signature Type Description
new_btree_map(by: fn(K, K) -> bool) <Self> Static Creates an empty map holding the comparator; the first allocation happens at birth and ensure_room doubles after that.
len() <int> Method How many pairs the map holds.
insert(key: K, value: V) <bool> Method Adds the pair, or replaces the value of a key that compares equal: true when the key is new, false when it replaced. O(n) worst case.
remove(key: K) <bool> Method Removes the pair whose key compares equal. True when something was removed, false when the key was not there.
find(key: K) <int> Method The index the sorted pair sits at, or -1 when the key is absent.
key_at(i: int) <K> Method The key at sorted position i. Index order is sorted order -- the determinism contract of the module. Blames when i is outside the filled range.
value_at(i: int) <V> Method The value at sorted position i. Blames when i is outside the filled range.
free_btree_map() <noret> Method Frees the two arrays. Stored key/value words are the caller's and are not touched.
Example 
import { BTreeMap } from btreemap::std;
import { compare } from strings::std;

fun main() <noret> {
    let scores <BTreeMap<string, int>> =
        BTreeMap::<string, int>::new_btree_map((a: string, b: string) <bool> => compare(a, b) < 0);
    scores.insert("Charlie", 92);
    scores.insert("Alice", 98);
    scores.insert("Bob", 85);

    blame scores.len() == 3;
    blame scores.key_at(0) == "Alice";
    blame scores.value_at(1) == 85;
    blame scores.find("Charlie") == 2;
    scores.free_btree_map();
}

intern

intern::std Collections

The string interner: same text, same id. Every scanner and the compiler's name tables want a stable id per text, answered without depending on a pointer word or a hash algorithm's history.

Note: v0 answers `intern` with one linear `compare(text, stored)` sweep (O(n), honestly documented): equality is strings::std's own content comparison, so a computed copy of a stored text lands on the stored id. Ids are the array index, stable for the interner's lifetime (the array only appends). Ownership: `intern` stores its own `clone` (a caller may free the string it interned); `resolve` answers the interned string, not a copy -- release everything with `free_interner`, never with `free_str`.
Import Statement 
import { Interner } from intern::std;

API Interface & Signatures

Signature Type Description
new_interner() <Self> Static Creates an empty interner with its first array; ensure_room doubles after that.
intern(text: string) <int> Method The id of text: an existing id when an equal text is stored (content comparison), or a fresh one appended. Stores its own copy.
resolve(id: int) <string> Method The text an id answers. Not a copy: the string belongs to the interner and is freed only by free_interner. Blames when id is outside the filled range.
size() <int> Method How many distinct texts the interner holds.
free_interner() <noret> Method Frees each stored copy and the array. Resolved strings are dead after this.
Example 
import { Interner } from intern::std;
import { equals } from strings::std;

fun main() <noret> {
    let names <Interner> = Interner::new_interner();
    let a <int> = names.intern("alpha");
    let again <int> = names.intern("alpha");
    blame again == a;
    let b <int> = names.intern("beta");
    blame b != a;
    blame equals(names.resolve(a), "alpha");
    names.free_interner();
}

reflect

reflect::std Types & Semantics

Reflection that runs (issue #53 Scope A): the module home of the four reflected intrinsics the compiler evaluates directly. Answers are folded from the facts the backend already lowers with -- a name compiles to an ordinary string literal, a measure to an ordinary integer constant -- so nothing is declared here yet and no import is needed: the builtins are the surface.

Note: The argument is a type’s name written where a type belongs (the same contextual reading @implements gets for its struct argument). @field_offset takes the field LITERAL -- only the backend fold can read a name at compile time -- which is also why fields_of is not shipped until a runtime FieldInfo has an owner for its name string. A payloaded enum refuses all four (it carries members, not fields; they come with enum_from!); an interface refuses (a fat value with no owning layout); a type parameter folds at the call’s turbofish on the C++ side and refuses on the stage side (one erased body). ADR 0057.
Import Statement 
// The reflected intrinsics are ambient beyond the module: no import.
// lib/std/reflect.fin documents the surface and its boundaries.

API Interface & Signatures

Signature Type Description
@type_name(T) <string> Intrinsic The declared name of the type the argument names; a scalar answers the spelling written (which is its name).
@type_size(T) <int> Intrinsic The DataLayout allocation size of the named type. A measure, an int -- not a layout width, so this deliberately did not copy the component API’s uint.
@field_count(T) <int> Intrinsic The declared field count; zero for anything fieldless, including a payloadless enum (it is the int its tag is).
@field_offset(T, "f") <int> Intrinsic The offset of the named field in declaration order. The field name must be the LITERAL: a run-time string cannot name a field at compile time.
Example 
struct Point { pub x <int>, pub y <long> }

fun main() <noret> {
    printf("%s\n", @type_name(Point));
    printf("%d %d\n", @type_size(Point), @field_count(Point));
    printf("%d\n", @field_offset(Point, "y"));
}

strings_example.fin

Import Statement

Signature Type Description

Memory & Safety Semantics: Enums carry member payloads inline. No heap allocation required.

Usage Example

typing_example.fin 
@define printf(fmt: string, ...) <noret>;
import { Result } from typing::std;

extern Result::Ok as Ok;
extern Result::Err as Err;

fun divide(num: int, denom: int) <Result<int, string>> {
    if (denom == 0) {
        return Err("Division by zero");
    }
    return Ok(num / denom);
}

fun main() <noret> {
    let ok_res <Result<int, string>> = divide(100, 4);
    blame ok_res.0 == 25;

    let err_res <Result<int, string>> = divide(10, 0);
    printf("Success: %d, Failure: %s\n", ok_res.0, err_res.0);
}

stdptr

stdptr::std Memory & Pointers

Smart pointer rptr<T> providing sound reference-counted memory sharing with explicit retain/release lifecycle tracking.

Note: Tracks shared reference count to prevent use-after-free and double-free defects.
Import Statement 
import { rptr, OwnershipError } from stdptr::std;

API Interface & Signatures

Signature Type Description
struct rptr<T> Struct Reference-counted pointer wrapping ptr <&T> and ref_count <int>. Methods: retain(), release(), get() <&T>, count() <int>.
enum OwnershipError Enum Ownership defect classification: DoubleFree, DanglingPointer, LeakDetected.
Memory & Safety Semantics: rptr tracks shared references. When the reference count reaches 0, the resource is released.

Usage Example

stdptr_example.fin 
@define printf(fmt: string, ...) <noret>;
import { rptr } from stdptr::std;

struct BufferHandle {
    fd <int>,
    capacity <int>
}

fun main() <noret> {
    let handle <BufferHandle> = BufferHandle { fd: 3, capacity: 4096 };
    let smart <rptr<BufferHandle>> = rptr<BufferHandle> { ptr: &handle, ref_count: 1 };

    smart.retain();
    blame smart.count() == 2;

    smart.release();
    blame smart.count() == 1;

    printf("Handle fd: %d, capacity: %d, active refs: %d\n", smart.get().fd, smart.get().capacity, smart.count());
}
